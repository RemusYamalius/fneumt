

## خطة التعديل على صفحة التحقق من الانخراط

### 1. استبدال خانة البحث بفلاتر منفصلة
بدل خانة بحث واحدة، سيتم إضافة **Select dropdown** للتصفية حسب:
- **الاسم** (قائمة بأسماء المسجلين)
- **رقم التأجير** (قائمة بأرقام التأجير)
- **اسم المؤسسة** (قائمة بالمؤسسات الفريدة)

كل فلتر يعمل بشكل مستقل ويمكن دمجهم معاً. مع زر لإعادة تعيين الفلاتر.

### 2. تلوين زر العودة
استبدال `Button variant="outline"` بزر مطابق لبقية الصفحات:
```
bg-gradient-to-r from-[hsl(207,75%,17%)] to-[hsl(207,62%,40%)] text-white rounded-full shadow-lg
```

### 3. تلوين بطاقات المسجلين حسب الحالة
- **منخرط مفعل (verified):** إطار أزرق + خلفية زرقاء خفيفة (`border-blue-200 bg-blue-50/50`)
- **قيد التحقق (pending):** إطار كهرماني + خلفية كهرمانية خفيفة (`border-amber-200 bg-amber-50/50`)
- **غير منخرط (not_member):** إطار رمادي + خلفية رمادية خفيفة (`border-gray-200 bg-gray-50/50`)
