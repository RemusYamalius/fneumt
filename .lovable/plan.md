

# إصلاح رسالة الترحيب + الرسوم البيانية + معلومات طلبات الانضمام

## المشاكل المكتشفة

### 1. رسالة الترحيب تظهر لمن لا يجب أن تظهر لهم
الشرط الحالي: `is_member === false && membership_verified === false` — وهذا ينطبق على كل حساب جديد قبل ملء الملف الشخصي. يجب إضافة شروط إضافية:
- **لا تظهر لذوي المناصب** (أي دور غير `teacher`)
- **لا تظهر إلا بعد ملء بيانات الملف الشخصي** (يجب أن تكون حقول `corps` و `academy` و `directorate` مملوءة)

**التعديل في `src/pages/Dashboard.tsx`:**
```typescript
const isNonMember = profile 
  && role === 'teacher'
  && profile.is_member === false 
  && profile.membership_verified === false
  && profile.corps && profile.academy && profile.directorate;
```
