

# خطة إعادة تصميم وتطوير المنصة

## ملخص المطلوب

المستخدم يطلب عدة تحسينات رئيسية:
1. تأكيد وتصحيح منطق التعيينات (كل منصب لا يعيّن إلا من هو أدنى منه مباشرة)
2. إعادة تصميم صفحة الطلبات الواردة بشكل Gmail-like مع فلاتر حسب الحالة
3. تغيير حالات الطلب إلى: مطلع عليه / قيد الإجراء / مقبول / ملغى
4. إضافة عرض المرفقات (PDF/صور فقط) + تقييد أنواع الملفات
5. إضافة بحث برقم التتبع + عرض التواريخ مع الساعة المحلية
6. تصميم احترافي بحركات انبثاق (McDonald's app style)
7. إزالة لوحة الإشراف من حساب المنسق المحلي

---

## التغييرات التقنية المطلوبة

### 1. تعديل قاعدة البيانات (Migration)

**تغيير enum الحالات**: الحالات الحالية هي `submitted, received, processing, resolved, rejected`. المطلوب الجديد:
- `submitted` → يبقى (تم الإرسال)
- `received` → يتغير إلى `viewed` (مطلع عليه)
- `processing` → يبقى كـ `in_progress` (قيد الإجراء)
- `resolved` → يتغير إلى `accepted` (مقبول)
- `rejected` → يتغير إلى `cancelled` (ملغى)

سيتم تحديث الـ enum وتحويل البيانات الموجودة.

### 2. تقييد أنواع المرفقات

تعديل صفحة `NewRequest.tsx` لقبول فقط: `application/pdf`, `image/*`. منع Word/Excel/Video.

### 3. إعادة تصميم صفحة الطلبات الواردة (`IncomingRequests.tsx`)

- تصميم Gmail-like: قائمة رسائل على اليسار، تفاصيل الطلب على اليمين
- **فلاتر** أعلى الصفحة: مطلع عليه / قيد الإجراء / مقبول / ملغى / الكل
- **بحث** برقم التتبع
- عند النقر على طلب: عرض كامل التفاصيل + المرفقات (مع إمكانية تحميلها/عرضها)
- **أزرار تغيير الحالة** أسفل كل طلب: مطلع عليه / قيد الإجراء / مقبول / ملغى (يمكن تغييرها في أي وقت)
- عرض التاريخ + الساعة المحلية
- حركات انبثاق باستخدام framer-motion

### 4. تعديل Dashboard.tsx

- إخفاء بطاقة "لوحة الإشراف" من حساب المنسق المحلي (`local_coordinator`)
- المنسق المحلي يرى فقط: طلب جديد + تتبع الملفات + الملف الشخصي + الطلبات الواردة + إدارة المستخدمين

### 5. تحديث role-hierarchy.ts

التأكد من أن منطق `getAllowedPromotions` مطابق تماماً للشرح:
- المشرف الجهوي يعيّن نوابه فقط
- نواب المشرف الجهوي يعيّنون المسؤولين الإقليميين
- المسؤول الإقليمي يعيّن نوابه فقط
- نواب المسؤول الإقليمي يعيّنون المنسقين المحليين
- المنسق المحلي يعيّن نوابه فقط

**ملاحظة**: المنطق الحالي صحيح تقريباً لكن يحتاج مراجعة دقيقة.

### 6. تحديث ترجمات i18n

إضافة/تعديل مفاتيح الترجمة للحالات الجديدة والفلاتر ونصوص الواجهة.

### 7. تحديث صفحة التتبع وإشعارات

تحديث `TrackRequest.tsx` و `useRealtimeNotifications.ts` للتوافق مع الحالات الجديدة + إضافة التوقيت المحلي.
