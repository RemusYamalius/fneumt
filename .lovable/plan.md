

# المرحلة 2: نظام المصادقة وقاعدة البيانات

## 1. إنشاء قاعدة البيانات (Database Migration)

إنشاء ملف migration يتضمن:

### الأنواع (Enums)
- `app_role`: teacher, union_officer, admin
- `request_category`: ملف طبي، مؤسسة محمد السادس، ترقيات، انتقال، الأصول، الانخراطات، المنح
- `request_status`: تم الإرسال، تم التوصل، قيد المعالجة، تمت التسوية، تم الرفض
- `corps_type`: ابتدائي، إعدادي، ثانوي، إداري

### الجداول
- **profiles**: مرتبط بـ auth.users، يحتوي على الاسم، رقم التأجير، السلك، المؤسسة، الهاتف، البريد، المنطقة، الأكاديمية، المديرية
- **user_roles**: جدول منفصل للأدوار (لمنع تصعيد الصلاحيات)
- **requests**: الطلبات مع رقم فريد وحالة ومسؤول معين
- **request_status_history**: تاريخ تغييرات الحالة
- **attachments**: المرفقات
- **comments**: ملاحظات النقابيين
- **notifications**: الإشعارات

### الدوال المساعدة (Security Definer Functions)
- `has_role(user_id, role)`: للتحقق من دور المستخدم بدون تكرار RLS
- `is_request_owner(request_id, user_id)`: هل المستخدم صاحب الطلب
- `is_assigned_officer(request_id, user_id)`: هل المستخدم هو النقابي المعين

### المحفزات (Triggers)
- **handle_new_user**: ينشئ تلقائياً ملف شخصي + دور "teacher" عند تسجيل مستخدم جديد
- **update_updated_at**: يحدث حقل updated_at تلقائياً

### سياسات RLS
- **profiles**: المستخدم يرى/يعدل ملفه فقط، الأدمين يرى الكل
- **user_roles**: الأدمين فقط يدير الأدوار، المستخدم يرى دوره
- **requests**: الأستاذ يرى طلباته، النقابي يرى الملفات المعينة له، الأدمين يرى الكل، الزائر يبحث برقم الملف
- **باقي الجداول**: وصول مبني على ملكية الطلب أو التعيين

### التخزين
- إنشاء bucket "attachments" خاص مع سياسات RLS

## 2. نظام المصادقة (Auth Context)

إنشاء `src/hooks/useAuth.tsx`:
- AuthProvider يغلف التطبيق
- يدير حالة المستخدم، الجلسة، الدور، والملف الشخصي
- دوال: signUp, signIn, signOut, resetPassword, updatePassword
- يستمع لتغييرات الجلسة عبر onAuthStateChange
- يجلب دور المستخدم وملفه الشخصي بعد تسجيل الدخول

## 3. صفحات المصادقة

### صفحة تسجيل الدخول (`src/pages/Login.tsx`)
- نموذج بريد إلكتروني + كلمة مرور
- زر إظهار/إخفاء كلمة المرور
- روابط: نسيت كلمة المرور، إنشاء حساب، العودة للرئيسية
- تصميم متناسق مع الصفحة الرئيسية (gradient-hero كخلفية)
- ثنائي اللغة (عربية/فرنسية)

### صفحة إنشاء حساب (`src/pages/Signup.tsx`)
- حقول: الاسم الكامل، البريد الإلكتروني، كلمة المرور
- رسالة نجاح بعد التسجيل تطلب التحقق من البريد
- التحقق من طول كلمة المرور (6 أحرف كحد أدنى)

### صفحة استعادة كلمة المرور (`src/pages/ForgotPassword.tsx`)
- حقل البريد الإلكتروني فقط
- رسالة تأكيد بعد الإرسال

### صفحة تعيين كلمة مرور جديدة (`src/pages/ResetPassword.tsx`)
- حقلا كلمة المرور الجديدة والتأكيد
- توجيه تلقائي للوحة التحكم بعد النجاح
