

# تأثير الزوايا المقعرة (Concave Corners) لتبويبات تسجيل الدخول

## المشكلة
حالياً الزوايا الداخلية للتبويب النشط (جهة النموذج الأبيض) مدورة للداخل مما يجعل الزر يبدو "مغلقاً" كحبة دواء. المطلوب هو تأثير "تبويب المتصفح" حيث تنحني الزوايا للخارج (مقعرة) فيبدو الزر "مفتوحاً" ومتصلاً بالنموذج الأبيض.

## الحل التقني
استخدام pseudo-elements (`::before` و `::after`) على التبويب النشط لإنشاء زوايا مقعرة (inverse border-radius):

```text
  ┌──────────────┐
  │   Blue panel  │
  │               ╮ ← ::before (concave curve)
  │  ┌────────────┘
  │  │  Active Tab (white)
  │  └────────────┐
  │               ╯ ← ::after (concave curve)  
  │               │
  └───────────────┘
```

## التغييرات — `src/index.css`

1. إزالة `border-radius: 1rem` من `.login-left-tab-active` واستبداله بتدوير خارجي فقط (الجهة البعيدة عن النموذج)
2. إضافة `::before` و `::after` على `.login-left-tab-active`:
   - حجم ~12px × 12px
   - خلفية شفافة مع `box-shadow` بلون أبيض لإنشاء القوس المقعر
   - موضع فوق وتحت الزر مباشرة على الجهة الداخلية (جهة النموذج)
3. تعديل قواعد RTL للتوافق مع الاتجاه المعاكس
