

# خطة: عرض العد التنازلي فوق محتوى الصفحة

## الوضع الحالي
حالياً عند ظهور العد التنازلي، يتم **استبدال** محتوى الصفحة بالكامل بالعد التنازلي فقط. المستخدم لا يرى العجلة المدارية ولا الخطوات.

## المطلوب
عرض كل محتوى صفحة "طلب جديد" (العجلة، الخطوات، الخلفية) بشكل **مرئي تحت** بطاقة العد التنازلي العائمة، مع:
- منع التفاعل مع المحتوى السفلي (pointer-events: none)
- السماح بالنقر على زر "العودة للوحة التحكم" فقط

## التعديلات

### 1. `src/pages/NewRequest.tsx`
- بدل إرجاع صفحة مختلفة للحالة 2 (teacher + قبل الموعد)، يتم عرض الصفحة العادية الكاملة مع إضافة `CountdownOverlay` فوقها
- تعطيل التفاعل مع باقي العناصر عبر CSS

### 2. `src/components/CountdownOverlay.tsx`
- إضافة `pointer-events: auto` للبطاقة نفسها فقط
- ضبط z-index ليكون فوق كل شيء
- إضافة زر "العودة للوحة التحكم" داخل البطاقة أو التأكد من أن الزر الأصلي يبقى قابلاً للنقر عبر `pointer-events: auto`
