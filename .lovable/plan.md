

# خطة: تحسين شامل للفلتر السريع — نتائج مدمجة + إصلاحات الخارطة والحلقات

## ملخص
تحويل صفحة الفلتر السريع من أداة توجيه (redirect) إلى أداة بحث مكتملة تعرض النتائج في نفس الصفحة مع إصلاحات كبيرة للخارطة والحلقات الدوارة.

## التغييرات بالتفصيل

### 1. نتائج البحث في نفس الصفحة (`QuickFilter.tsx`)
- حذف التوجيه إلى `/database`
- إضافة state للنتائج + تنفيذ query مباشرة على `profiles` عبر Supabase
- عرض جدول نتائج أسفل الفلتر مع scroll تلقائي عند الضغط على "بحث"
- الجدول يتضمن: checkbox لكل صف + checkbox "الكل" في الرأس
- زر "مراسلة" أسفل الجدول → يفتح `PostComposer` مع الاحتفاظ بالأشخاص المحددين كمستلمين

### 2. إصلاح الخارطة (`MoroccoMap.tsx`)

**a) إحصائيات ديناميكية:**
- الإحصائيات الجانبية تتغير حسب الجهة والإقليم المختار (حالياً تعمل فقط على مستوى الجهة)

**b) زر الرجوع:**
- عند النقر على رجوع، إعادة `selectedRegion` إلى `null` في `QuickFilter.tsx` لضمان ظهور أسماء كل الجهات

**c) تباين النص على الخارطة:**
- حساب luminance لكل لون جهة/إقليم واختيار لون خط فاتح أو داكن تلقائياً
- إضافة `textShadow` / stroke للأسماء لضمان القراءة

**d) زر تكبير الشاشة (Fullscreen):**
- إضافة زر expand في زاوية الخارطة يحولها لـ fullscreen modal مع أنيميشن
- صوت نقر عند التكبير/التصغير
- الحفاظ على الاختيارات الحالية (جهة/إقليم) عند التصغير
- زر الرجوع الموجود يعيد كل شيء للحالة الأولى

### 3. إصلاح الحلقات الدوارة (`OrbitalFilter.tsx`)

**a) إيقاف الدوران عند hover:**
- إصلاح الـ animation لتتوقف فعلياً (حالياً تسرع) — المشكل في `framer-motion` transition config
- الحلقة تتوقف عند اختيار عنصر منها (لا تعود للدوران)

**b) إصلاح النص المقلوب:**
- إعادة كتابة منطق `textRotation` لضمان أن كل النصوص مقروءة (ليست مقلوبة)
- تكبير الخط عند hover على الزر/الشريحة

**c) تأثيرات بصرية:**
- تكبير الشريحة عند hover (scale) مع أنيميشن
- لمعان (glow) على الشرائح المختارة بعد النقر
- الحلقات غير المختار منها تستمر بالدوران، والمختار منها تتوقف

### 4. جدول النتائج (مكون جديد: `SearchResultsTable.tsx`)
- جدول احترافي: الاسم، الأكاديمية، المديرية، المهمة، الانخراط، الهاتف
- checkbox أمام كل شخص + checkbox "الكل" في Header
- أنيميشن ظهور + scroll إليه تلقائياً
- زر "مراسلة المختارين" أسفل الجدول

## الملفات المتأثرة
```
src/pages/QuickFilter.tsx              (نتائج بحث مدمجة + state + scroll + رابط المراسلة)

src/components/MoroccoMap.tsx          (تباين النص + fullscreen + إحصائيات ديناميكية + رجوع)
src/components/SearchResultsTable.tsx  (مكون جديد: جدول نتائج مع checkboxes)
```
