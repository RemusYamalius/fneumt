

# تطبيق شكل الإنفوغرافيك على بطاقات الصفحة الرئيسية

## الوصف
تحويل البطاقات الثلاث إلى تصميم يشبه الصورة المرجعية: أقواس نصف دائرية ملونة فوق دوائر الأيقونات، متصلة بخط أفقي مع نقاط.

## التصميم المستهدف
```text
     ╭──╮         ╭──╮         ╭──╮
    │    │       │    │       │    │
    ╰─(●)─╯     ╰─(●)─╯     ╰─(●)─╯
       │            │            │
  ─────●────────────●────────────●─────
       │            │            │
    العنوان       العنوان       العنوان
     الوصف        الوصف        الوصف
```

## التفاصيل التقنية

### تعديل `src/pages/Index.tsx` — قسم البطاقات
- استبدال `card-premium` بتصميم جديد لكل بطاقة:
  - **قوس نصف دائري ملون** فوق الأيقونة باستخدام `border` مع `border-b-0` و `rounded-t-full`
  - ألوان الأقواس: أحمر/برتقالي، أصفر/ذهبي، رمادي داكن (كما في الصورة)
  - **دائرة بيضاء** بظل تحتوي الأيقونة، متداخلة مع أسفل القوس
  - **خط عمودي** قصير يصل الدائرة بالخط الأفقي
- إضافة **خط أفقي مع 3 نقاط** بين البطاقات (عنصر منفصل أسفل الشبكة)
- العنوان والوصف أسفل الخط الأفقي

### الألوان المستخدمة (من الصورة المرجعية)
- البطاقة 1: `#C0392B` (أحمر)
- البطاقة 2: `#F39C12` (ذهبي)
- البطاقة 3: `#2C3E50` (رمادي داكن)

### لا تعديلات على ملفات أخرى
- التعديل محصور في `src/pages/Index.tsx` فقط (JSX + inline styles أو Tailwind classes)
