

# خطة: استبدال الجزء الأيسر بفلتر دائري متحرك بتسع حلقات

## ملخص
حذف مكون `OrbitalStats` من الجزء الأيسر للصفحة واستبداله بمكون جديد `OrbitalFilter` — تسع حلقات متحدة المركز تدور كل واحدة عكس الأخرى، كل حلقة تمثل عنصر فلتر واحداً. مع محدد أولي (المسجلون / المكاتب المحلية) في المركز، وصوت نقر عند كل تفاعل.

## العناصر التسعة (من الصورة المرجعية)
1. **الأكاديمية** — يتعبأ تلقائياً عند النقر على جهة في الخارطة
2. **المديرية** — يتعبأ عند النقر على إقليم
3. **المؤسسة** — حقل نصي
4. **النوع** (الجنس) — ذكر/أنثى/الكل
5. **الإطار/المهمة** — قائمة المهام
6. **الفئة العمرية** — Min / Max
7. **حالة الانخراط** — منخرط/غير منخرط/قيد الانتظار/الكل
8. **رقم التأجير** (N°PPR) — حقل نصي
9. **رقم الهاتف** — حقل نصي

## التصميم البصري

```text
        ┌──────────────────────────┐
        │   حلقة 9: رقم الهاتف     │
        │  ┌────────────────────┐  │
        │  │  حلقة 8: N°PPR     │  │
        │  │ ┌────────────────┐ │  │
        │  │ │ ... 7 حلقات   │ │  │
        │  │ │  ┌──────────┐  │ │  │
        │  │ │  │  المركز   │  │ │  │
        │  │ │  │ مسجلون/   │  │ │  │
        │  │ │  │ مكاتب    │  │ │  │
        │  │ │  └──────────┘  │ │  │
        │  │ └────────────────┘ │  │
        │  └────────────────────┘  │
        └──────────────────────────┘
```

- كل حلقة = دائرة SVG أو div مع `border-radius: 50%` تدور ببطء
- الحلقات الفردية تدور في اتجاه عقارب الساعة، والزوجية عكسها
- كل حلقة تحمل اسم الفلتر (label) كنقطة قابلة للنقر على محيطها
- عند النقر على نقطة الفلتر: يظهر popover/dropdown صغير لاختيار القيمة
- ألوان متعددة من لوحة الألوان المرجعية (عجلة الألوان): كل حلقة بلون مختلف من تدرجات متناسقة
- **المركز**: زر تبديل بين "المسجلون" و"المكاتب المحلية"

## التفاعلات
- النقر على جهة في الخارطة ← يملأ حلقة "الأكاديمية" تلقائياً مع أنيميشن توهج
- النقر على إقليم ← يملأ حلقة "المديرية"
- كل نقرة على أي عنصر ← صوت نقر خفيف (iPhone keyboard tick) يتم توليده بـ `AudioContext` (Web Audio API) بدون ملف صوتي خارجي
- زر "بحث" في الأسفل ← يطبق الفلاتر ويعرض النتائج (أو ينتقل لصفحة قاعدة البيانات مع الفلاتر)
- زر "إعادة ضبط" ← يمسح كل الفلاتر

## التنفيذ التقني

### ملفات جديدة
- **`src/components/OrbitalFilter.tsx`** — المكون الجديد بالكامل (الحلقات التسع + المركز + التفاعلات)
- **`src/hooks/useClickSound.ts`** — hook لتوليد صوت النقر عبر Web Audio API

### ملفات معدلة
- **`src/pages/QuickFilter.tsx`** — استبدال `OrbitalStats` بـ `OrbitalFilter`، تمرير الفلاتر الحالية (academy, directorate) من الخارطة، إضافة زر بحث + عرض نتائج أو توجيه
- **`src/components/OrbitalStats.tsx`** — يبقى كما هو (قد يُستخدم في أماكن أخرى)

### التقنيات
- `framer-motion` لدوران الحلقات + AnimatePresence للـ popovers
- `Popover` من shadcn/ui لعرض خيارات كل فلتر
- Web Audio API (OscillatorNode) لصوت النقر بدون ملفات خارجية
- ألوان الحلقات: تدرج من الداخل للخارج باستخدام ألوان مستوحاة من عجلة الألوان المرفقة
