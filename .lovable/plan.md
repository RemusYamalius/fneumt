

# منصة FNE-UMT سيدي بنور الرقمية

## الهوية البصرية
- ألوان مستوحاة من شعار النقابة: أزرق ملكي (#2874A6)، كحلي (#1B4F72)، مع لمسات خضراء (#228B22) وحمراء (#cc0404) كألوان ثانوية
- تصميم عصري وشبابي مع تدرجات (gradients)، ظلال ناعمة، وتأثيرات glass morphism
- خط Tajawal للعربية و Roboto للفرنسية
- شعار النقابة يُعرض في الصفحة الرئيسية
- مساحات بيضاء واسعة، زوايا مستديرة، وحركات انتقالية سلسة

---

## المرحلة 1: الأساسيات والواجهة الرئيسية

### الصفحة الرئيسية
- واجهة ترحيبية أنيقة مع تدرج لوني أزرق كخلفية للقسم العلوي (Hero)
- شعار النقابة في الأعلى مع عنوان المنصة
- ثلاثة أزرار/بطاقات رئيسية بتصميم عصري مع أيقونات: **طلب جديد** | **تتبع الملفات** | **تسجيل الدخول**
- تبديل اللغة (عربية/فرنسية) مع دعم RTL/LTR
- تذييل (Footer) بمعلومات التواصل

### نظام المصادقة (Supabase Auth)
- صفحة تسجيل الدخول بالبريد الإلكتروني وكلمة المرور
- صفحة تسجيل حساب جديد للأساتذة
- استعادة كلمة المرور
- جدول `profiles` لبيانات المستخدم (الاسم، رقم التأجير، السلك، المؤسسة، الهاتف، المنطقة، الأكاديمية، المديرية)
- جدول `user_roles` منفصل للأدوار (teacher, union_officer, admin)
- سياسات RLS محكمة لكل دور

---

## المرحلة 2: نظام الطلبات

### نموذج طلب جديد
- نموذج متعدد الخطوات (Wizard) بتصميم أنيق
- حقول: الاسم الكامل، رقم التأجير، السلك، المؤسسة، الهاتف، البريد الإلكتروني
- نوع الطلب (ملف طبي، مؤسسة محمد السادس، ترقيات، انتقال، الأصول، الانخراطات، المنح)
- رفع وثائق (PDF وصور) عبر Supabase Storage مع معاينة قبل الإرسال
- توليد رقم ملف فريد تلقائياً (رقم التأجير + التاريخ + رقم ترتيبي)
- عرض رقم الملف بوضوح بعد الإرسال مع إمكانية النسخ

### تتبع الملفات
- صفحة بحث برقم الملف أو رقم التأجير (متاحة بدون تسجيل دخول)
- شريط تتبع بصري عصري للحالة بخمس مراحل مع أيقونات ملونة:
  - ✅ تم الإرسال بنجاح
  - 📥 تم التوصل بالملف
  - ⏳ قيد المعالجة
  - ✅ تمت تسوية الملف
  - ❌ تم رفض الملف
- عرض تاريخ كل تغيير في الحالة (Timeline) لتعزيز الشفافية

---

## المرحلة 3: لوحات التحكم

### لوحة الأستاذ (teacher)
- قائمة طلباته مع بطاقات ملونة حسب الحالة
- إمكانية إضافة طلب جديد
- عرض تفاصيل كل طلب مع الوثائق

### لوحة النقابي (union_officer)
- عرض الملفات الموكلة إليه
- فلترة حسب نوع الطلب وحالة المعالجة
- تغيير حالة الملف وإضافة ملاحظات
- عداد للملفات حسب الحالة

### لوحة الأدمين (admin)
- إحصائيات ورسوم بيانية عصرية (Recharts): عدد الطلبات، نسب المعالجة، توزيع حسب النوع
- عرض شامل لجميع الملفات مع فلترة متقدمة
- إدارة المستخدمين وتعيين الأدوار
- تعيين ملفات للنقابيين
- استخراج تقارير CSV

---

## المرحلة 4: الإشعارات

### نظام الإشعارات
- إشعارات داخل المنصة (جرس إشعارات في شريط التنقل)
- إشعار بريد إلكتروني عبر Edge Function عند:
  - وصول طلب جديد → للنقابي المسؤول
  - تغيير حالة الملف → لصاحب الطلب

---

## قاعدة البيانات (Supabase)
- `profiles` - بيانات المستخدمين مع حقول region/academy/delegation
- `user_roles` - الأدوار منفصلة
- `requests` - الطلبات مع رقم فريد
- `request_status_history` - تاريخ تغييرات الحالة
- `attachments` - المرفقات
- `comments` - ملاحظات النقابيين
- `notifications` - الإشعارات
- سياسات RLS وفهارس للأداء
