

# خطة: إنشاء "ركن التواصل" - نظام منشورات داخلي احترافي

## الفكرة العامة
إنشاء نظام تواصل داخلي يشبه شبكة اجتماعية مهنية، حيث تستطيع الحسابات الثلاثة السامية (admin, national_secretary, deputy_national_secretary) إنشاء منشورات غنية (نص + إيموجي + صور + PDF + فيديو + روابط) وإرسالها لفئات محددة عبر فلاتر متقدمة. يتلقى المستخدمون المستهدفون المنشورات في "ركن التواصل" الخاص بهم مع إمكانية الإعجاب فقط (بدون مشاركة).

---

## 1. قاعدة البيانات (4 جداول جديدة + Storage bucket)

### جدول `posts`
| العمود | النوع | الوصف |
|---|---|---|
| id | uuid PK | |
| author_id | uuid NOT NULL | المنشئ |
| content | text | النص |
| filters | jsonb | الفلاتر المستخدمة لتحديد المستلمين |
| created_at | timestamptz | |
| updated_at | timestamptz | |

### جدول `post_attachments`
| العمود | النوع | الوصف |
|---|---|---|
| id | uuid PK | |
| post_id | uuid FK → posts | |
| file_path | text | مسار في Storage |
| file_name | text | اسم الملف |
| mime_type | text | نوع الملف |
| file_size | integer | |

### جدول `post_recipients`
| العمود | النوع | الوصف |
|---|---|---|
| id | uuid PK | |
| post_id | uuid FK → posts | |
| user_id | uuid | المستلم |
| is_read | boolean DEFAULT false | هل فتح المنشور |
| read_at | timestamptz | |

### جدول `post_likes`
| العمود | النوع | الوصف |
|---|---|---|
| id | uuid PK | |
| post_id | uuid FK → posts | |
| user_id | uuid | المعجب |
| created_at | timestamptz | |
| UNIQUE(post_id, user_id) | | |

### Storage bucket: `post-attachments` (خاص)

### سياسات RLS
- **posts**: القيادة العليا تقرأ/تكتب/تحدث/تحذف. المستلمون يقرأون فقط عبر `post_recipients`.
- **post_recipients**: المؤلف يدرج. المستلم يقرأ ويحدث `is_read`.
- **post_likes**: المستلم يدرج/يحذف إعجابه. المؤلف يقرأ الكل.
- **post_attachments**: المؤلف يدرج. المستلمون يقرأون.
- Realtime على `post_recipients` لإشعار المستلمين فوراً.

## 2. الملفات الجديدة

### `src/pages/CommunicationHub.tsx`
صفحة "ركن التواصل" الرئيسية تعرض:
- **للحسابات الثلاثة**: تبويبان:
  1. **إنشاء منشور**: محرر نصي غني مع إيموجي picker + رفع مرفقات (صور/PDF/فيديو) + معاينة المرفقات كمصغرات قابلة للنقر + فلاتر متقدمة لاختيار المستلمين (نفس فلاتر قاعدة البيانات: الاسم، PPR، الأكاديمية، المديرية، المؤسسة، الإطار، حالة الانخراط، المناصب، السن...) + زر نشر
  2. **إحصاءات المنشورات**: لائحة المنشورات بمقتطفات احترافية، عند النقر تظهر: تاريخ النشر، عدد المستلمين، فئتهم، عدد من فتح المنشور، بيانات من اطلع، عدد الإعجابات، بيانات المعجبين
- **لباقي الحسابات**: عرض المنشورات الموجهة إليهم كـ "صفحة فيسبوك" مع إمكانية الإعجاب فقط

### `src/components/PostComposer.tsx`
مكون محرر المنشور:
- Textarea مع emoji picker (استخدام مكتبة `emoji-mart` أو picker بسيط مدمج)
- منطقة رفع الملفات (drag & drop + click) تقبل صور/PDF/فيديو/روابط
- معاينة المرفقات كمصغرات أسفل النص (صورة مصغرة / أيقونة PDF / فيديو مصغر)
- المرفقات قابلة للنقر لفتحها
- فلاتر المستلمين القابلة للطي (Collapsible)
- عداد المستلمين المتوقعين

### `src/components/PostFeed.tsx`
مكون عرض المنشورات (لباقي الحسابات):
- تصميم يشبه فيسبوك/لينكدإن بلون أزرق ملكي مستقبلي
- كل منشور يعرض: اسم الناشر + تاريخ + النص + المرفقات المصغرة القابلة للنقر + زر الإعجاب
- عند فتح المنشور يُحدث `is_read = true`
- لا يوجد زر مشاركة

### `src/components/PostStats.tsx`
مكون إحصاءات المنشورات (للحسابات الثلاثة):
- لائحة المنشورات بمقتطفات
- عند النقر: Dialog يعرض كل الإحصاءات + إمكانية التعديل/إعادة النشر/الحذف
