

# تطبيق تصميم الأزرار والبطاقات الزجاجية من الصورة المرجعية

## التحليل
الصورة تُظهر تصميم على خلفية **رمادية-زرقاء متوسطة** (ليست بيضاء ولا داكنة) مع عناصر زجاجية شفافة ذات:
- حواف رفيعة بيضاء شبه شفافة (glass border)
- خلفية شفافة مع blur خفيف
- نص أبيض/رمادي فاتح
- ظل داخلي خفيف يعطي عمق
- أزرار دائرية (السهم) وأزرار بيضاوية (Button) بنفس النمط الزجاجي

## التعديلات

### 1. `src/index.css`
- **`.profile-white-bg`**: تغيير الخلفية إلى تدرج رمادي-أزرق متوسط مشابه للصورة (`hsl(200 10% 58%)` → `hsl(210 8% 48%)`)
- **`.profile-card-glass`**: خلفية شفافة رمادية (`rgba(255 255 255 / 0.08)`) + حدود بيضاء رفيعة (`rgba(255 255 255 / 0.25)`) + ظل داخلي خفيف
- **`.profile-card-glass.active`**: نفس النمط مع توهج أقوى
- **`.profile-input`**: خلفية شفافة + حدود بيضاء رفيعة + نص أبيض
- **`.profile-save-btn`**: نمط زجاجي بيضاوي مثل الصورة (شفاف + حدود بيضاء + نص أبيض) بدل التدرج الأزرق
- **`.profile-summary-card`**: نفس النمط الزجاجي
- **`.profile-delete-btn`**: حواف زجاجية مع لمسة حمراء خفيفة
- أزرار التنقل (prev/next): دائرية زجاجية مع حدود بيضاء شفافة

### 2. `src/pages/Profile.tsx`
- تحديث ألوان النصوص من الداكنة إلى الفاتحة (بيضاء/رمادي فاتح) لتناسب الخلفية الرمادية
- تحديث أزرار التنقل لتطبيق النمط الزجاجي (حدود بيضاء شفافة + خلفية شفافة)
- تحديث أيقونات الدوائر (icon circles) بنفس النمط
- تحديث ألوان الجسيمات العائمة لتكون بيضاء شفافة
- تحديث شريط التقدم والنقاط
- تحديث ألوان العنوان والعداد

### النمط الزجاجي المستهدف (من الصورة)
```css
/* البطاقة / الزر */
background: rgba(255 255 255 / 0.06);
backdrop-filter: blur(16px);
border: 1px solid rgba(255 255 255 / 0.2);
box-shadow: inset 0 1px 0 rgba(255 255 255 / 0.1),
            0 4px 20px rgba(0 0 0 / 0.15);
color: rgba(255 255 255 / 0.85);
```
