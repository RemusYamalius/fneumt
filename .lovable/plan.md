

# تحويل فلاتر جدول بطائق الانخراط إلى رؤوس أعمدة تفاعلية + تحسين الألوان

## ملخص
- إزالة شريط البحث المنفصل فوق الجدول
- تحويل رؤوس الأعمدة إلى فلاتر تفاعلية: النقر على رأس العمود يفتح إما خيارات (مثل ذكر/أنثى) أو حقل بحث نصي مع اقتراحات
- إضافة ألوان متناسقة لبطاقتي "تشكيل المكتب" و"بطائق الانخراط"

## التغييرات في `src/pages/LocalOffice.tsx`

### 1. استبدال شريط البحث بفلاتر في رؤوس الأعمدة

حالة جديدة للفلاتر:
```typescript
const [columnFilters, setColumnFilters] = useState({
  full_name: '',
  employee_number: '',
  gender: '' as '' | 'male' | 'female',
  institution: '',
});
const [activeFilter, setActiveFilter] = useState<string | null>(null);
```

كل رأس عمود يصبح قابلا للنقر:
- **الاسم**: نقر → يظهر حقل Input صغير مدمج تحت العنوان، يفلتر فوريا
- **رقم التأجير**: نقر → حقل Input صغير مدمج
- **النوع**: نقر → قائمة منسدلة بخيارات (الكل / ذكر / أنثى)
- **المؤسسة**: نقر → حقل Input صغير مع اقتراحات (autocomplete من القيم الموجودة)
- **رقم البطاقة** و**حالة الدفع**: لا فلتر (لأنها حقول تعديل)

عند النقر على رأس عمود مفعّل، يُخفى الفلتر. مؤشر بصري (أيقونة فلتر أو لون مختلف) يدل على الفلتر النشط.

### 2. ألوان متناسقة (وفق نظام الألوان المعتمد)

**بطاقة تشكيل المكتب:**
- رأس البطاقة: خلفية تدرج أزرق خفيف `bg-blue-50 border-blue-200`
- أيقونة `Users`: `text-blue-600`
- شارات المناصب: تدرجات لونية حسب المنصب (الكاتب=أزرق، أمين المال=كهرماني، المقرر=بنفسجي، المستشار=رمادي)
- زر الحفظ: يبقى `primary`

**بطاقة بطائق الانخراط:**
- رأس البطاقة: خلفية تدرج أخضر خفيف `bg-emerald-50 border-emerald-200`
- أيقونة `CreditCard`: `text-emerald-600`
- شارة "مدفوع": `bg-green-100 text-green-700`
- شارة "غير مدفوع": `bg-red-50 text-red-500`
- رؤوس الأعمدة القابلة للفلتر: لون مميز عند التمرير `hover:text-blue-600` مع cursor-pointer
- بطاقات الملخص المالي: كل بطاقة بلون مختلف (المستخلص=أخضر، المتبقي=كهرماني، المدفوع للإقليمي=أزرق)

**جدول تشكيل المكتب (الأعضاء الحاليون):**
- رؤوس الأعمدة: `bg-blue-50/50`
- صفوف متبادلة الألوان خفيفة

**جدول بطائق الانخراط:**
- رؤوس الأعمدة: `bg-emerald-50/50`
- فلتر نشط: رأس العمود يتحول للون المميز
