

# خطة: إعادة تنظيم "فلاتر متقدمة" مع اختيار النوع أولاً

## الفكرة
عند النقر على "فلاتر متقدمة"، تظهر أولاً بطاقتان عائمتان جميلتان: **المسجلون** و **المكاتب المحلية**. بعد اختيار إحداهما، تظهر خانات الفلترة المناسبة في بطاقة عريضة بخلفية شفافة مع ظل على الخانات. يُضاف زر **"بحث"** بجانب زر "إعادة ضبط الفلاتر".

## التعديلات في `src/pages/DatabaseDashboard.tsx`

### 1. إضافة حالة جديدة لاختيار نوع البحث
- إضافة `filterCategory` state: `'none' | 'users' | 'offices'` (يبدأ بـ `'none'`)
- عند فتح الفلاتر، إذا لم يُختر نوع، تظهر البطاقتان فقط

### 2. تصميم بطاقتي الاختيار
- بعد فتح الفلاتر، تظهر بطاقتان بتصميم عائم (shadow-xl، rounded-2xl، hover scale) بأيقونة وعنوان:
  - بطاقة **المسجلون** (أيقونة Users، تدرج أزرق)
  - بطاقة **المكاتب المحلية** (أيقونة Building2، تدرج زمردي)
- عند النقر على إحداهما، تتحول `filterCategory` وتظهر الخانات مع أنيميشن

### 3. إظهار الخانات بعد الاختيار
- الخانات الحالية تظهر داخل حاوية بخلفية شبه شفافة (`bg-background/40 backdrop-blur-sm`)
- كل خانة فلتر تحصل على `shadow-md` لتبرز
- تظهر فقط الفلاتر المناسبة للنوع المختار (المسجلون أو المكاتب)

### 4. إضافة زر "بحث"
- يُضاف زر **"بحث"** (ملون بتدرج أزرق، أيقونة Search) على يمين زر "إعادة ضبط الفلاتر"
- الزر يُفعّل البحث الفعلي ويضبط الـ `currentPage` إلى 1

### 5. ربط الاختيار مع التبويبات
- اختيار "المسجلون" أو "المكاتب المحلية" في الفلاتر يُغيّر أيضاً التبويب النشط (Tabs value) ليتطابق مع الاختيار

## التفاصيل التقنية
- `filterCategory` state يتحكم في مرحلتي العرض (اختيار النوع ← إظهار الخانات)
- الفلاتر لا تُطبق مباشرة عند التغيير بل عند النقر على "بحث" (أو يمكن إبقاء الفلترة الفورية كما هي مع إضافة الزر كتأكيد بصري)
- `AnimatePresence` + `motion.div` للانتقال بين المرحلتين
- عند إعادة ضبط الفلاتر، يعود إلى مرحلة اختيار النوع
