

# تعديل أزرار التبويب في الجانب الأيسر لتبدو مندمجة مع قسم النموذج

## الفكرة
الزر النشط يجب أن يظهر كأنه جزء من اللوحة البيضاء (قسم النموذج) — حوافه الخارجية (أعلى وأسفل من جهة اللوحة الزرقاء) دائرية، بينما الجهة المواجهة للنموذج مفتوحة/مسطحة تماماً بدون حواف دائرية، مما يخلق تأثير الاندماج.

```text
   ┌──────────────────────────────────┐
   │  Blue Panel                      │
   │                   ╭─────────╮    │
   │                   │ LOGIN   │────│── متصل بالأبيض
   │                   ╰─────────╯    │
   │                                  │
   │                    SIGN IN       │
   │                                  │
   └──────────────────────────────────┘
```

الزر النشط: `border-radius` دائري فقط من الجهة اليسرى (أو اليمنى في RTL)، مسطح من جهة النموذج. يمتد إلى حافة اللوحة اليسرى ليلامس اللوحة البيضاء.

## التعديلات — `src/index.css` فقط

1. **`.login-left-tab`**: إزالة `border-radius` العام، إضافة عرض كافٍ
2. **`.login-left-tab-active`**: 
   - `border-radius: 1rem 0 0 1rem` (دائري يسار، مسطح يمين)
   - في RTL: `border-radius: 0 1rem 1rem 0`
   - خلفية بيضاء + ظل
   - إزاحة الزر ليمتد حتى حافة اللوحة اليسرى عبر `margin-inline-end: -1px` أو `position: relative` مع تعديل
3. **حاوية الأزرار** (في Login.tsx): تعديل لتكون الأزرار على الحافة اليمنى من اللوحة اليسرى بدلاً من المنتصف

## الملفات المعدلة
- `src/index.css` — تعديل `.login-left-tab-active` border-radius + positioning
- `src/pages/Login.tsx` — تعديل حاوية الأزرار لتكون `items-end` بدلاً من `items-center` + إضافة padding مناسب
