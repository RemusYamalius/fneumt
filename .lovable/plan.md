

# ترقية الحساب إلى أدمين وبناء لوحة إدارة المستخدمين

## المرحلة 1: ترقية الحساب

تحديث دور المستخدم JAMAL EL KADIRI من `teacher` إلى `admin` في جدول `user_roles`.

## المرحلة 2: لوحة إدارة المستخدمين (صفحة /admin/users)

صفحة محمية لا يصل إليها إلا الأدمين، تتضمن:

1. **جدول المستخدمين** -- عرض جميع المستخدمين مع بياناتهم (الاسم، البريد، الدور الحالي، السلك، المؤسسة)
2. **تغيير الأدوار** -- قائمة منسدلة لتعيين دور كل مستخدم (معلم / نقابي مسؤول / أدمين)
3. **تعيين الطلبات** -- إمكانية تعيين طلبات لنقابي مسؤول محدد

## المرحلة 3: تحديث سياسات قاعدة البيانات

- إضافة سياسة RLS تسمح للأدمين بعرض جميع الملفات الشخصية (موجودة بالفعل)
- التأكد من أن الأدمين يمكنه تعديل أدوار المستخدمين (موجودة بالفعل)

## التفاصيل التقنية

### تغييرات قاعدة البيانات
- تحديث بيانات: `UPDATE user_roles SET role = 'admin' WHERE user_id = '6afc6ed1-...'`
- لا حاجة لتغييرات هيكلية، السياسات والجداول جاهزة

### الملفات الجديدة
- `src/pages/admin/UserManagement.tsx` -- صفحة إدارة المستخدمين مع جدول وأزرار تغيير الأدوار
- `src/components/RoleGuard.tsx` -- مكون حماية يمنع غير الأدمين من الوصول

### الملفات المعدّلة
- `src/App.tsx` -- إضافة مسار `/admin/users`
- `src/pages/Dashboard.tsx` -- إضافة رابط "إدارة المستخدمين" يظهر فقط للأدمين
- `src/lib/i18n.tsx` -- إضافة ترجمات لوحة الإدارة

### واجهة إدارة المستخدمين
- جدول يعرض: الاسم الكامل، البريد الإلكتروني، الدور، السلك، المؤسسة
- قائمة منسدلة لتغيير الدور مباشرة من الجدول
- زر حفظ التغييرات مع إشعار نجاح
- تصميم متوافق مع الثيم الحالي (RTL + ثنائي اللغة)
