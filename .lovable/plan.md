

# خطة: إعادة تصميم الفلتر الدائري على شكل عجلة ألوان بأقواس مقسمة

## الفكرة
إعادة بناء `OrbitalFilter.tsx` بالكامل ليشبه عجلة الألوان في الصورة المرجعية — كل مدار عبارة عن حلقة مقسمة لأقواس/شرائح (arc segments) تشكل أزراراً قابلة للنقر. الحلقات ذات البيانات الكثيرة أو حقول الإدخال النصي تظهر في لوحة جانبية على اليسار.

## تقسيم الحلقات التسع (من الداخل للخارج)

| # | الفلتر | عدد الشرائح | النوع |
|---|--------|-------------|-------|
| 1 | النوع (ذكر/أنثى/الكل) | 3 أقواس | شرائح دائرية |
| 2 | حالة الانخراط | 4 أقواس (منخرط/غير/قيد/الكل) | شرائح دائرية |
| 3 | الإطار/المهمة | 11 قوساً | شرائح دائرية |
| 4 | الأكاديمية | 12 قوساً (12 جهة) | شرائح دائرية |
| 5 | المديرية | شرائح ديناميكية حسب الأكاديمية المختارة | شرائح دائرية (تتغير) |
| 6 | المؤسسة | — | لوحة جانبية (حقل نص) |
| 7 | الفئة العمرية | — | لوحة جانبية (min/max) |
| 8 | رقم التأجير PPR | — | لوحة جانبية (حقل نص) |
| 9 | رقم الهاتف | — | لوحة جانبية (حقل نص) |

## التصميم البصري

```text
   ┌─────────────────────────┐  ┌────────────────┐
   │                         │  │  لوحة الإدخال   │
   │    ╭─ المديرية ──╮      │  │                │
   │   ╭─ الأكاديمية ─╮     │  │  المؤسسة: ___  │
   │  ╭─── المهمة ────╮     │  │  العمر: _-_    │
   │  │╭─ الانخراط ─╮ │     │  │  PPR: ______   │
   │  ││╭─ النوع ─╮ │ │     │  │  الهاتف: _____ │
   │  │││ المركز  │ │ │     │  │                │
   │  │││مسجلون/  │ │ │     │  │  [بحث] [ضبط]   │
   │  ││╰─────────╯ │ │     │  └────────────────┘
   │  │╰────────────╯ │     │
   │  ╰───────────────╯     │
   │   ╰──────────────╯      │
   │    ╰─────────────╯       │
   └─────────────────────────┘
```

- كل حلقة = SVG path arcs ملونة بألوان من عجلة الألوان المرفقة
- عند النقر على شريحة: تتلون (selected) وتُصدر صوت نقر
- الحلقات الفردية تدور ببطء في اتجاه والزوجية عكسه (مع توقف عند hover)
- المركز: زر تبديل مسجلون/مكاتب

## لوحة الألوان (مستوحاة من الصورة)
- الحلقة الداخلية (النوع): تدرجات وردية/بنفسجية `#C77EB5`, `#8E6BAF`, `#E8A0BF`
- الانخراط: تدرجات زرقاء `#4A6FA5`, `#6B9BC3`, `#2C4A7C`, `#89B4D4`
- المهمة: تدرجات خضراء/تيل من 11 لوناً
- الأكاديمية: تدرجات دافئة (برتقالي/أصفر/أحمر) 12 لوناً
- المديرية: تدرجات ترابية/بنية
