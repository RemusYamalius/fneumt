

# إصلاح ترتيب الأعمدة + ترجمة مبيان الإطار

## المشكلتان

1. **ترتيب أعمدة الجدول معكوس**: حالياً الترتيب الحالي (دور ← انخراط ← هاتف ← ... ← اسم) هو ما يجب أن يكون في **الفرنسية** (LTR). في **العربية** (RTL) يجب أن يكون العكس: اسم ← نوع ← تاريخ الازدياد ← ... ← دور.
   
   **الحل**: عكس ترتيب الأعمدة في الـ `<thead>` و `<tbody>` ليصبح: الاسم أولاً ← النوع ← تاريخ الازدياد ← PPR ← الإطار ← الأكاديمية ← المديرية ← المؤسسة ← الهاتف ← الانخراط ← الدور. هذا الترتيب الطبيعي (LTR) سيظهر صحيحاً لأن المتصفح يعكسه تلقائياً مع `dir="rtl"` على الجدول.

2. **مبيان التوزيع حسب الإطار باللغة الإنجليزية**: الصورة تُظهر `teaching`, `teacher` كأسماء أعمدة المبيان. رغم وجود `getMissionLabel` في `missionChartData`، يبدو أن بعض القيم في قاعدة البيانات (مثل `teaching`, `teacher`) غير مدرجة في `MISSION_VALUE_TO_KEY` فتُعرض كما هي.

   **الحل**: إضافة القيم المفقودة (`teaching`, `teacher`, وأي قيم أخرى محتملة) إلى `MISSION_VALUE_TO_KEY` مع ربطها بمفاتيح الترجمة المناسبة.
