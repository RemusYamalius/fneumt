

# إعادة تصميم صفحة تسجيل الدخول

## الوصف
إعادة تصميم صفحة Login لتطابق شكل الصورة المرجعية: تصميم ذو عمودين مع أشكال هندسية مائلة على اليسار (بتدرج أزرق ملكي)، وقسم النموذج على اليمين مع اللوغو فوقه يتحرك صعودا ونزولا.

## التصميم المستهدف
```text
┌─────────────────────────────────────────┐
│                                         │
│  ┌──────────┬──────────────────────────┐ │
│  │  ◇       │      (AnimatedLogo)      │ │
│  │   ◇◇     │       ↕ floating         │ │
│  │  LOGIN◇  │        LOGIN             │ │
│  │  SIGN IN │                          │ │
│  │    ◇◇    │   📧 Email               │ │
│  │          │   🔒 Password            │ │
│  │          │                          │ │
│  │          │   Forgot?    [LOGIN]     │ │
│  └──────────┴──────────────────────────┘ │
│                                         │
└─────────────────────────────────────────┘
```

## التعديلات المطلوبة

### 1. `src/pages/Login.tsx` — إعادة هيكلة كاملة
- **الجانب الأيسر (showcase):** حذف الصورة والنصوص، استبدالها بأشكال هندسية مائلة (chevrons/arrows) باستخدام CSS/divs بتدرج أزرق ملكي (من `hsl(207 75% 17%)` إلى `hsl(207 62% 40%)`)
- تبويبان "LOGIN" و "SIGN IN" على الجانب الأيسر (أو الأيمن في RTL)
- **الجانب الأيمن (panel):** اللوغو AnimatedLogo في الأعلى مع عنوان "LOGIN"/"SIGN IN"
- حقول البريد وكلمة المرور مع أيقونات على يسارها
- رابط "نسيت كلمة المرور" وزر Submit
- **حذف:** خيارات التواصل الاجتماعي (غير موجودة أصلا)، حذف badge/kicker/subtitle الحالية

### 2. `src/index.css` — إضافة keyframe للتحريك العمودي
```css
@keyframes logo-float {
  0%, 100% { transform: translateY(0); }
  50% { transform: translateY(-6px); }
}
.animate-logo-float {
  animation: logo-float 3s ease-in-out infinite;
}
```

### 3. تصميم الأشكال الهندسية المائلة
- 3 طبقات مائلة (chevron shapes) باستخدام `clip-path` أو `transform: skewY()` بتدرجات مختلفة من الأزرق الملكي
- تأثير material design layered مشابه للصورة المرجعية

### الملفات المعدلة
- `src/pages/Login.tsx` — إعادة هيكلة JSX
- `src/index.css` — إضافة keyframe + تعديل أنماط auth
