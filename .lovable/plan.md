

# نموذج تقديم طلب جديد + صفحة تتبع الملفات

## 1. نموذج تقديم طلب جديد (`/new-request`)

صفحة محمية (تتطلب تسجيل الدخول) بنموذج متعدد الخطوات:

### الخطوة 1: اختيار الفئة
- عرض 7 فئات كبطاقات قابلة للنقر (ملف طبي، مؤسسة محمد السادس، ترقيات، انتقالات، ممتلكات، اشتراكات، منح دراسية)

### الخطوة 2: الموضوع والوصف
- حقل الموضوع (نص قصير، إلزامي)
- حقل الوصف (نص طويل، اختياري)

### الخطوة 3: إرفاق الملفات
- منطقة سحب وإفلات للملفات أو زر اختيار
- معاينة الملفات المرفقة مع إمكانية الحذف
- حد أقصى 5 ملفات، 10MB لكل ملف

### الخطوة 4: المراجعة والإرسال
- عرض ملخص الطلب (الفئة، الموضوع، الوصف، الملفات)
- زر إرسال
- بعد الإرسال: عرض رقم التتبع مع إمكانية نسخه

## 2. صفحة تتبع الملفات (`/track`)

صفحة عامة (لا تتطلب تسجيل دخول):

- حقل بحث لإدخال رقم التتبع
- عرض النتائج: الفئة، الموضوع، الحالة الحالية، تاريخ التقديم
- شريط تقدم بصري يوضح المراحل الخمس (مقدّم، مستلم، قيد المعالجة، تمت المعالجة، مرفوض)
- رسالة خطأ واضحة إذا لم يُعثر على الرقم

## التفاصيل التقنية

### الملفات الجديدة
- `src/pages/NewRequest.tsx` -- نموذج الطلب متعدد الخطوات مع رفع الملفات إلى bucket "attachments"
- `src/pages/TrackRequest.tsx` -- صفحة البحث بالرقم التتبعي

### الملفات المعدّلة
- `src/App.tsx` -- إضافة مسارات `/new-request` و `/track`
- `src/lib/i18n.tsx` -- إضافة ترجمات جديدة (أسماء الفئات، خطوات النموذج، حالات الطلب، رسائل التتبع)

### منطق الإرسال
1. إنشاء سجل في جدول `requests` (الفئة، الموضوع، الوصف، user_id) -- يتم توليد tracking_number تلقائياً
2. رفع الملفات إلى Storage bucket "attachments" بمسار `{user_id}/{request_id}/{file_name}`
3. إنشاء سجلات في جدول `attachments` لكل ملف مرفق
4. عرض رقم التتبع للمستخدم

### منطق التتبع
- استعلام جدول `requests` بفلتر `tracking_number`
- سياسة RLS "Anyone can search by tracking number" موجودة بالفعل وتسمح بالقراءة العامة
- لا حاجة لتغييرات في قاعدة البيانات

### سياسات التخزين (Storage)
- إضافة سياسة RLS لبucket "attachments" تسمح للمستخدمين المسجلين برفع الملفات في مجلدهم الخاص
